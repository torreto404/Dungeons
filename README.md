# 🗡️ Текстовая RPG / Dungeon Crawler на C (Ещё в разработке!)

Консольная пошаговая ролевая игра с элементами Rogue-like, написанная на чистом языке C. Проект построен по строгой модульной архитектуре с разделением на независимые компоненты данных, логики и интерфейса.

---

## 🎮 Описание игры
Вы управляете героем, который исследует опасное подземелье в поисках главного Босса. Подземелье представляет собой этаж, состоящий из комнат, скрытых плотным «туманом войны». Каждая комната таит в себе неизвестность: вы можете найти проход дальше, наткнуться на сундук или активировать случайное боевое столкновение с монстром. 

---

## ✨ Текущие возможности и особенности

### 🗺️ Исследование и механика карты
* **Пошаговое перемещение:** Навигация по двумерной матрице лабиринта с помощью классических клавиш `W`, `A`, `S`, `D`.
* **Туман войны (Fog of War):** Карта полностью скрыта на старте. Комнаты и стены динамически раскрываются в радиусе обзора вокруг персонажа с помощью умных вложенных циклов.
* **Случайные встречи (Random Encounters):** 25% шанс встретить бродячего монстра при переходе в любую неисследованную комнату.
* **Клетка Босса:** Уникальная финальная комната со смертоносным лидером подземелья, охраняющим переход.

### ⚔️ Боевая система и ИИ
* **Пошаговые дуэли:** Интерактивное боевое меню для игрока (Атака, Блок, Использование зелий).
* **Умный ИИ противника:** Враг оценивает ситуацию на своем ходу: при низком здоровье пьет зелья, при высоком — сбалансированно выбирает между атакой и уходом в глухую защиту (блок).
* **Тактическое добивание:** Компьютер симулирует расчет урона сквозь броню игрока. Если ИИ понимает, что может нанести летальный урон, он игнорирует самолечение и наносит добивающий удар.
* **Механика Блокирования:** Персонажи могут поднять щит на один ход, чтобы с шансом заблокировать половину входящего урона. Флаги защиты строго контролируются и сбрасываются в начале каждого действия.

### 🎒 Инвентарь и Кастомизация
* **Глобальный справочник (Database):** Централизованный каталог чертежей всех игровых предметов (оружие, шлемы, нагрудники, зелья).
* **Независимые рюкзаки (Backpacks):** У каждого персонажа и монстра есть собственный изолированный инвентарь в памяти, работающий по адресам указателей.
* **Система стаканья (Stacking):** Расходники (зелья здоровья) хранятся в одной ячейке с динамическим счетчиком количества (`quantity`).
* **Гибкая кастомизация:** Интерактивное меню создания персонажа перед стартом игры, позволяющее ввести имя и собрать стартовый loadout вручную или выбрать готовый стандартный набор.

## 🛠️ Архитектура проекта

Проект разделен на логические модули для удобства поддержки и расширения:
* `types.h` — структуры данных игры (`Character`, `Inventory`, `Weapon`, `Position`).
* `init.c` / `init.h` — наполнение мирового справочника предметов.
* `character.c` / `character.h` — базовая инициализация персонажей и выдача стартовых наборов.
* `game.c` / `game.h` — расчет урона, защита, лечение и интерактивные меню выбора вещей.
* `combat.c` / `combat.h` — пошаговый цикл проведения боя и управление раундами.
* `ai.c` / `ai.h` — логика принятия решений компьютерным оппонентом.
* `map.c` / `map.h` — отрисовка подземелья, перемещение персонажа и обработка тумана войны.
* `main.c` — точка входа, инициализация консоли и главное меню игры.

## 🚀 Сборка и запуск

Проект компилируется с помощью компилятора `GCC` (MinGW / MSYS2).

Для автоматической сборки используйте готовый командный файл `build.bat`:
1. Запустите `build.bat` из корневой директории проекта.
2. Исполняемый файл будет скомпилирован и сохранен в папку `bin/main.exe`.
3. Либо используйте уже готовый `bin/main.exe`.
